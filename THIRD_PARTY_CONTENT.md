The files under `skill_collection/` are a research corpus assembled from publicly available third-party skill materials. They are not authored by the Code Skill Server project unless a file explicitly says otherwise. Copyright and other rights in each skill remain with its original author or rights holder.

The collection is provided for non-commercial research and educational use, including reproducibility, analysis, retrieval experiments, and academic evaluation. It is not offered for commercial use. ## Scope of the Apache-2.0 license

The root `LICENSE` applies only to original project code and documentation, including the collection, filtering, auditing, export, validation, and continuous-integration code. It expressly excludes the contents of `skill_collection/`.

## Attribution and corrections

Users should cite the Code Skill Server paper when using the assembled corpus and should also attribute original skill authors and repositories where that information is available. The current integrity manifest records released paths and content hashes; it is not a complete upstream-license inventory.

If you are a rights holder and believe material has been attributed incorrectly or should not appear in this research release, please open a GitHub issue identifying the affected skill path and supporting source information. The maintainers will review correction or removal requests.
