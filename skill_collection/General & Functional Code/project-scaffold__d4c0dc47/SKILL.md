# Project Scaffold

> **Priority:** `core` · **Layer:** `frontend`

Genera estructura base del proyecto frontend: carpetas, tsconfig, ESLint, env tipado.

## What This Skill Covers

- Estructura de carpetas por feature o tipo
- tsconfig.json estricto con path aliases
- ESLint + Prettier con reglas de proyecto
- Variables de entorno tipadas
- README de onboarding

## When to Activate

Al iniciar cualquier proyecto nuevo o estandarizar uno existente.
