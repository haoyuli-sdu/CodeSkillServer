# Code Helper Suite

Anthropic官方出品的开发专用技能套件，包含6个核心功能，支持多种编程语言的代码调试、生成和优化。

## 触发词
- "代码调试"
- "代码生成"
- "语法检查"
- "优化代码"
- "/code-helper"

## 执行步骤
1. 理解用户的代码需求或问题
2. 分析代码结构和语法
3. 执行相应的代码操作
4. 返回结果和优化建议

## 功能说明
### 1. 代码调试
- 自动识别代码问题
- 标注错误位置
- 给出修改建议

### 2. 代码生成
- 根据需求生成代码
- 支持多种编程语言
- 优化代码格式

### 3. 语法检查
- 检查代码语法错误
- 提供修复建议
- 优化代码结构

### 4. 代码注释
- 自动生成代码注释
- 优化现有注释
- 提升代码可读性

### 5. 代码重构
- 优化代码结构
- 提升代码性能
- 修复逻辑漏洞

### 6. API调用示例
- 生成第三方库调用示例
- 提供使用说明
- 优化API调用方式

## 支持语言
- Python
- JavaScript/TypeScript
- Java
- C/C++
- Go
- Rust
- 其他主流编程语言

用户: "帮我优化这段Python代码"
