# PyCryptodome (Crypto) — Symmetric and Asymmetric Cryptography

## AES Encryption with MODE_EAX

`AES.MODE_EAX` provides authenticated encryption (confidentiality + integrity). The
nonce is generated automatically and accessible via `cipher.nonce`:

```python
from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes
from base64 import b64encode

key = get_random_bytes(16)           # 16, 24, or 32 bytes for AES-128/192/256
cipher = AES.new(key, AES.MODE_EAX)
nonce = cipher.nonce                 # auto-generated bytes; save for decryption

ciphertext, tag = cipher.encrypt_and_digest(b"plaintext data")
encoded = b64encode(ciphertext).decode('utf-8')
```

Decryption requires the same key and nonce:
```python
decipher = AES.new(key, AES.MODE_EAX, nonce=nonce)
plaintext = decipher.decrypt_and_verify(ciphertext, tag)
```

## Encrypting an RSA Private Key with AES

A common pattern: generate an RSA key pair, serialize the private key to PEM bytes,
then encrypt those bytes with AES-EAX:

```python
import rsa, os
from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes
from base64 import b64encode

(pub_key, priv_key) = rsa.newkeys(512)
password = get_random_bytes(16)

cipher = AES.new(password, AES.MODE_EAX)
nonce = cipher.nonce
priv_pem = priv_key.save_pkcs1()             # bytes — use save_pkcs1(), not save_pem()
ciphertext, tag = cipher.encrypt_and_digest(priv_pem)

filename = f'private_key_{os.urandom(8).hex()}.txt'
with open(filename, 'w') as f:
    f.write(b64encode(ciphertext).decode('utf-8'))

return pub_key, filename, password, nonce
```

`rsa.PrivateKey` has `save_pkcs1()` but no `save_pem()` method.

## Random Bytes

```python
from Crypto.Random import get_random_bytes
key = get_random_bytes(16)     # cryptographically secure random bytes
```

`get_random_bytes(n)` is equivalent to `os.urandom(n)`.

## Return Types

```
AES.new(key, AES.MODE_EAX)              → cipher object (nonce at .nonce)
cipher.encrypt_and_digest(data)         → (ciphertext_bytes, tag_bytes)
decipher.decrypt_and_verify(ct, tag)    → plaintext_bytes
get_random_bytes(n)                     → bytes
```

## AES Key Size

AES accepts exactly 16 (128-bit), 24 (192-bit), or 32 (256-bit) bytes as the key.
Other sizes raise `ValueError: AES key must be either 16, 24, or 32 bytes long`.
